# UmbrElla

UmbrElla, as its name suggests, is a collection of Gecko codes I have written for Mario Golf: Toadstool Tour.
These codes works on the PAL version only though, since that's the only version of the game I own.

## Repository Structure

On the root directory, every file or folder corresponds to one gecko code.
For simple code generated from only one assembly file, that assembly file is placed in the root directory.
For complex ones generated from multiple assmebly files, those assembly files are grouped into a folder in the root directory.
