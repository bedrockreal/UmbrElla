# UmbrElla

This repository contains the Assembly source code of the PAL-only Gecko Codes I have written for Mario Golf: Toadstool Tour.

The file `GFTP01.ini` is a Dolphin `.ini` file containing both the codes (in text format) and their description. You can use the codes from it directly (e.g. placing the file in your Dolphin game config folder) if you wish, but it might not reflect the latest version.
To get the latest codes, run `make` to assemble them. You need to have `DevkitPPC` installed.
